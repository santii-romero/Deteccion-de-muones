# Deteccion-de-muones
Repositorio del proyecto de detección y conteo de muones con mediciones de detectores oficiales


## Laboratorio de enseñanza: centelladores

La carpeta [Muones](Muones/README.md) contiene el código, las decisiones y los resultados reproducibles de esta etapa. Integrantes: **Theo Del Compare y Santiago Romero**.

- [Informe PDF](Muones/output/pdf/proyecto_muones.pdf) de cinco páginas.
- [Informe HTML autónomo](Muones/output/informe.html) para descargar y abrir en el navegador.
- [Instrucciones de reproducción](Muones/docs/REPRODUCIBILIDAD.md).

Las mediciones originales y los respaldos grandes se conservan localmente fuera del repositorio. La integración de ambas etapas y la revisión editorial de los informes quedan pendientes.

El trabajo del detector profesional se conserva en la rama [identificador](https://github.com/santii-romero/Deteccion-de-muones/tree/identificador/Proyecto-detector).
